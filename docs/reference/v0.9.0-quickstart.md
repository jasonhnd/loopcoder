# v0.9.0 quickstart (V090-080)

Issue: [#1194](https://github.com/jasonhnd/loopcoder/issues/1194)

## Install (Darwin arm64)

```bash
# product installer path (version pinned by release)
curl -fsSL https://raw.githubusercontent.com/jasonhnd/loopcoder/main/scripts/install.sh | sh -s -- --version 0.9.0
loopcoder version
```

## First run

```bash
loopcoder doctor                 # read-only preflight; prefer --format json for CI
loopcoder doctor --format json
```

## Ordinary development (not self-bootstrap)

v0.9 ordinary development does **not** use `loopcoder compile`, `dispatch`, or
`tick` against the LoopCoder repository. Use:

1. Isolated worktree / branch from `pre-prod` (or your product base)
2. Implement one issue
3. PR with required checks (verify/test/race/security)
4. Merge + exact-SHA integration-verify + integration-canary dual green
5. Human merge gate for production

## Status, events, cancel, providers

```bash
loopcoder status                 # v0.9 stores only (no parallel progress writers)
# provider inventory/route explain via official adapters only
# cancel/resume through accepted workflow/direct-run facades
```

## Migration

```bash
loopcoder migrate export-v08 --export-dir /tmp/v08-export --fixture   # or --source-dir; read-only
loopcoder migrate import-v09 --export-dir /tmp/v08-export             # dry-run default
loopcoder migrate import-v09 --export-dir /tmp/v08-export --apply     # transactional per project
# compatibility aliases also work: loopcoder export-v08 / loopcoder import-v09
```

## Storage and privacy

- Global/project stores under `$LOOPCODER_HOME` — **no** production writes to
  customer `<repo>/.loopcoder`
- Private content redacted per `internal/privacy` policy
- Cross-Mac: terminal GitHub rehydration only — no DB sync

## Unsupported (honest)

Autonomous compile/tick/trigger, federation, cross-Mac leases, repo-local
runtime sidecars, v0.8 mutation from the v0.9 binary.

See [capability matrix](v0.9.0-capability-matrix.md).
