This is the binding release-evidence record for LoopCoder v0.8.0.

## Release Contract

- Supported tuple: native macOS Apple Silicon (`darwin/arm64`) only.
- Unsupported: Windows, Linux/Ubuntu, WSL, containers used as a LoopCoder
  runtime, Intel macOS, and Rosetta/amd64 macOS.
- Legacy fallback: v0.7.0, the final legacy multi-platform release.
- Binary asset: `loopcoder_0.8.0_darwin_arm64.tar.gz` only.
- Integrity material: `SHA256SUMS`, `SHA256SUMS.sigstore`, and the release
  workflow's verifiable signing/provenance evidence.
- Required PR checks: `verify`, `test`, `race`, and `security` on pinned
  `macos-15`, with an asserted Darwin arm64 Go host.
- Publication authority: protected `release-publication` environment with a
  required human reviewer.

## Migration And Rollback Review

Before GO, verify that:

1. migration planning creates or modifies no file;
2. apply creates one owner-only, integrity-checked schema-9 backup;
3. schema versions 10 through 30 commit atomically;
4. repeated apply returns `no-op`;
5. all LoopCoder processes are stopped before apply or rollback;
6. rollback copies rather than mutates the backup;
7. the published v0.7.0 binary opens the copied backup; and
8. the operator acknowledges that rollback discards v0.8-only state.

Never point v0.7.0 at the schema-30 database.
