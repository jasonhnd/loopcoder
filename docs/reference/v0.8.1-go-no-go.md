# v0.8.1 Go/No-Go Gate

This is the **product-path** go/no-go gate for LoopCoder v0.8.1 on native
macOS Apple Silicon (`darwin/arm64`). It complements the historical
[`v0.8.0 go/no-go report`](v0.8.0-go-no-go.md) by proving the shipped candidate
reaches the capabilities claimed after the v0.8.1 production-closure work
([#1002](https://github.com/jasonhnd/loopcoder/issues/1002)).

For the end-to-end operator sequence (freeze → fixture → packaged → live
canaries → optional Apple trust → tag → publish → close tracking), use the
[`v0.8.1 release runbook`](v0.8.1-release-runbook.md).

## One command

```bash
# Deterministic fixture gate (CI-safe; no paid providers; Apple dry-run only)
bash scripts/v081-product-path-gate.sh \
  --mode fixture \
  --artifact-dir ./gate-evidence \
  --candidate-sha "$(git rev-parse HEAD)"

# Packaged candidate (exact binary later published)
bash scripts/v081-product-path-gate.sh \
  --mode packaged \
  --binary ./loopcoder \
  --expected-digest <sha256> \
  --candidate-sha <git-sha> \
  --artifact-dir ./gate-evidence

# Product-path Full GO (blocking live Codex/Claude; Apple live optional)
bash scripts/v081-product-path-gate.sh \
  --mode packaged \
  --binary ./loopcoder \
  --expected-digest <sha256> \
  --candidate-sha <git-sha> \
  --include-live-canaries 1 \
  --artifact-dir ./gate-evidence

# Optional Gatekeeper-friendly public download path (when Developer ID is available)
bash scripts/v081-product-path-gate.sh \
  --mode packaged \
  --binary ./loopcoder \
  --expected-digest <sha256> \
  --candidate-sha <git-sha> \
  --include-live-canaries 1 \
  --include-apple-live 1 \
  --artifact-dir ./gate-evidence
```

Outputs:

| File | Purpose |
| --- | --- |
| `v081-go-no-go-evidence.json` | Machine-readable `loopcoder.v081_go_no_go.v1` |
| `v081-go-no-go-report.md` | Human-readable gate table |
| `logs/*` | Per-gate command logs (redacted) |
| `evidence/*` | Nested matrix, canary, codesign artifacts |

Exit `0` = **GO** for the requested mode. Exit `1` = **NO-GO**.

## Required product paths

The gate records each of the following. Fixture mode runs harnesses that do not
need a paid provider. Packaged mode adds nested permission matrix and CLI
surface probes against the exact binary. Live canaries and live Apple trust are
**never** implied by fixture success.

| Gate | Fixture | Packaged | Full GO |
| --- | --- | --- | --- |
| Source hygiene | yes | yes | yes |
| Installer default + custom PATH | yes | yes | yes |
| Codex/Claude canary fixtures | yes | yes | yes |
| Apple codesign dry-run harness | yes | yes | yes |
| Product CLI surfaces (version/platform/doctor/route/wait/delivery/status) | optional | yes | yes |
| Nested permission matrix (packaged) | optional | yes | yes |
| Live Codex canary | not_run | not_run unless flagged | **required** |
| Live Claude canary | not_run | not_run unless flagged | **required** |
| Live Apple Developer ID + notarize | not_run | not_run unless flagged | **recommended** (optional; request with `--include-apple-live 1`) |
| Non-blocking Grok/Antigravity | not_run | not_run | recorded not_run (#1021) |
| Open release-blockers = 0 | warn/not_run | warn until full | required on full |

**Product-path Full GO** = packaged binary gates + live Codex/Claude canaries +
zero open release-blockers. It does **not** require a local Apple Developer ID
certificate. Unsigned or Sigstore-only CLI archives remain valid publication
modes (source install, Homebrew formula, `go build`, owner-shared tarballs).

**Live Apple trust** remains the path for Gatekeeper-friendly DMG/download UX
when a Developer ID identity and notary profile are configured. Request it
explicitly; when requested and it fails, the gate records `fail` for that run.

## Go criteria

1. Every v0.8.1 `release-blocker` issue is closed by a merged PR.
2. Every **required** gate above passes on one frozen candidate SHA/artifact.
3. README / capability matrix match observed product behavior.
4. No P0/P1 defect remains; lower-severity limits are explicit and assigned to v0.9.0.
5. Owner approves the protected publication environment for public GitHub Release.
6. Live canaries (and optional Apple live, if claimed) run against the **same
   digest** later published.

## No-go behavior

- Leave the GitHub Release as draft/unpublished.
- Report the failed gate name, detail, and log basename from the evidence JSON.
- Open or reopen only one narrowly scoped blocker with owner approval.
- Do not restart the entire roadmap or treat fixture success as real-provider evidence.
- Do not treat missing Apple credentials as product NO-GO unless
  `--include-apple-live 1` was explicitly requested.
